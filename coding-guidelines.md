# Javascript:
- https://google.github.io/styleguide/jsguide.html
- https://jscs-dev.github.io/
- For Javascript, we went with the Google style guide. We chose to use this set of coding guidelines because it forces strict naming conventions, which helps to eliminate confusion when components written by separate programmers need to interface with each other. Furthermore, it enforces JSDoc annotations for all functions, which means our devs are required to write proper documentation for their code. Finally, we will use JSCS, which is a Javascript linter, which can verify that code follows the Google style guidelines.
# HTML/CSS:
- https://google.github.io/styleguide/htmlcssguide.html
- https://validator.w3.org/nu/
- For HTML/CSS, we also chose to use Google’s style guide. We chose Google’s style guide for the sake of parity. Because the Java script we are writing will need to interact with our HTML & CSS, it only makes sense to have them share styling rules. We will verify this with the Nu HTML Checker, as specified by Google’s style guide.
